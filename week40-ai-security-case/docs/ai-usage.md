# AI- och Källredovisning

## Verktyg
- **AI-modell:** ChatGPT / Gemini (Large Language Model)

## Användningsområde
- AI-verktyget användes som ett bollplank för att strukturera rapporten enligt mallen för Case A, generera idéer kring verifieringsmetoder samt översätta den engelska sammanfattningen.

## Verifiering och Egna Korrigeringar
- **Faktaavgränsning:** AI-modellen föreslog initialt att bekräfta att "angreppet genomfördes med AI/LLM". Detta korrigerades manuellt eftersom givna fakta tydligt anger att AI-användning endast är en möjlighet och inte ett fastställt faktum.
- **Antal åtgärder:** AI-modellen genererade ursprungligen fem åtgärdsförslag. Detta begränsades manuellt till exakt tre prioriterade åtgärder i enlighet med instruktionerna för Case A.
- **CIS Controls:** Kontrollerades mot den officiella CIS Controls v8.1-standarden för att säkerställa att benämningar och numrering stämde exakt.
