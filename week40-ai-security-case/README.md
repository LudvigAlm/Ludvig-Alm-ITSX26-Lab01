# AI Security Case Investigation - Vecka 40

**Student:** Individual Assignment  
**Kurs:** ITSX26 - AI Security  
**Valt Case:** Case A – AI-phishing mot en kommun (Sikte G)  

## Beskrivning av Repository
Detta repository innehåller den individuella examinationsrapporten för Case A i kursvecka 40. Analysen behandlar en misstänkt AI-assisterad phishing-incident riktad mot en kommunal förvaltning.

## Repository-struktur
- `README.md` - Kort beskrivning av valt case och repositoryt.
- `docs/report.md` - Huvudrapport (Svenska).
- `docs/english_security_summary.md` - English Security Summary (100–150 words).
- `docs/references.md` - Källförteckning och referenser.
- `ai_usage.md` - Redovisning av AI-användning, verifiering och egna korrigeringar.
- `evidence/` - Mapp för tekniska bilagor, figurer och stödjande material.
